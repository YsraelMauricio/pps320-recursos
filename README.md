# Recursos iniciales para PPS-320

Este repositorio público contiene únicamente los dos puntos de partida que se entregan durante la primera semana:

- `plantilla.html`: entregar al inicio de la práctica del Día 2.
- `dia_03_inicio/`: entregar al inicio de la práctica del Día 3.

Descarga una copia desde GitHub (botón **Code → Download ZIP**) o clona el repositorio. No compartas las carpetas de referencia `dia_01/` a `dia_05/` como ejercicios iniciales: contienen soluciones posteriores.

Curso PPS-320, EventosUSFA. Sin datos de estudiantes ni secretos.
