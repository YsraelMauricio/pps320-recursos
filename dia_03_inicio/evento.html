Taller

Taller de Git y GitHub para principiantes

Organiza: Centro de Estudiantes de Sistemas

Fecha
sábado 5 de diciembre de 2026, 09:00 a 12:00
Lugar
Laboratorio 3, Edificio de Sistemas
Cupos
12 disponibles de 30

Descripción

En este taller práctico de tres horas aprenderás a crear repositorios, guardar cambios con commits claros, trabajar con ramas y colaborar mediante pull requests en GitHub. No se necesita experiencia previa; solo trae tu laptop.

¿Qué aprenderás?

  • Crear y clonar repositorios
  • Escribir mensajes de commit útiles
  • Trabajar con ramas y resolver conflictos simples
  • Abrir y revisar un pull request
